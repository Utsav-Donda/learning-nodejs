# Security Policy

This is a personal learning repository containing educational Node.js examples. It is not a production library or service, but if you spot a security issue in one of the examples (e.g. an insecure pattern being taught without a warning), please report it.

## Reporting a Vulnerability

Please open a [GitHub issue](../../issues) describing the concern, or reach out directly via the contact on the [GitHub profile](https://github.com/Utsav-Donda) if it involves sensitive details that shouldn't be public.

There's no bug bounty here — just an ask that insecure patterns get flagged so the learning material stays accurate.
